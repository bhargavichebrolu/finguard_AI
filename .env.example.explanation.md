# .env.example

Source: [.env.example](.env.example)

## A. File Purpose
Lists every environment variable the project reads, with placeholder values. PRD section 10 requires this file to contain placeholders only.

## B. Why This File Exists
A new developer needs to know which settings exist without seeing anyone's secrets. `scripts/generate_env.py` uses it as the template for a real `.env`.

## C. Dependencies
- **Libraries / tools:** none.
- **Internal files:** `.gitignore` ignores `.env` but keeps this file.
- **External services / database:** none.
- **Depended on by:** `scripts/generate_env.py`, `docker-compose.yml` by name, and `backend/app/core/config.py`.

## D. Every Function Explained
No functions. The variables:

### `APP_ENV`
`development`, `test` or `production`. Production applies stricter checks on start-up.

### `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, `POSTGRES_HOST_PORT`
The database superuser, the main database and the port published on this computer. The superuser is for administration only.

### `APP_DB_USER`, `APP_DB_PASSWORD`, `TEST_DB_NAME`
The non-superuser role the API uses, and the name of the test database.

### `DATABASE_URL`, `TEST_DATABASE_URL`
Connection addresses for running on the host. Inside Compose, `DATABASE_URL` is rebuilt to use the `db` host. Test fixtures refuse a test URL whose database name does not end in `_test`.

Use `127.0.0.1`, not `localhost`. Compose publishes IPv4 only, and on Windows `localhost` tries IPv6 (`::1`) first. Measured on the development computer: `127.0.0.1` connected in 0.02 s, `::1` never answered, and `localhost` took 4 s with a 4 s timeout and hung indefinitely with no timeout.

### `SECRET_KEY`
Signs login tokens. It must be at least 32 characters, and anyone holding it can forge a token.

### `CORS_ALLOWED_ORIGINS`
Comma-separated browser origins allowed to call the API. Cookie requests that change data must also come from one of these. The template lists the Vite development (5173) and preview (4173) servers.

### `TRUSTED_PROXY_IPS`
Proxies whose `X-Forwarded-For` header is believed. Empty trusts nobody. Wildcards are refused.

### `SESSION_COOKIE_SECURE`
Commented out by default, which means Secure in production only. Production refuses `false`.

### `API_HOST_PORT`, `VITE_API_BASE_URL`
The port the API is published on, and where the Phase 4 frontend will look for it.

## H. Important Technical Concepts
- **Letters and digits in passwords.** Passwords go inside connection URLs, where characters like `@` or `/` would change the meaning. Generated passwords are hexadecimal for this reason.
- **`VITE_*` values reach the browser**, so they must never hold a secret.

## I. Example
```powershell
uv run --project backend python scripts/generate_env.py --db-port 5432 --api-port 8010
```

## J. Maintenance Notes
