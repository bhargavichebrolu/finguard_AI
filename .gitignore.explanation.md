# .gitignore

Source: [.gitignore](.gitignore)

## A. File Purpose
Keeps secrets, datasets, model binaries and generated files out of Git.

## B. Why This File Exists
PRD section 10 forbids committing `.env`, secrets, private keys and data exports. PRD section 13 forbids committing the full dataset and unnecessary model binaries. A mistake here is hard to undo once something is pushed, so these exclusions are enforced by default rather than left to care.

## C. Dependencies
- **Libraries / tools:** Git.
- **Internal files:** none.
- **External services / database:** none.
- **Depended on by:** `scripts/generate_env.py`, which refuses to write `.env` unless Git ignores it.

## D. Every Function Explained
No functions. The groups:

### Secrets
`.env`, `.env.*`, `*.pem` and `*.key`, with `.env.example` and its explanation document explicitly allowed. The explanation exception was added in Phase 3, after a count showed `.env.example.explanation.md` had matched `.env.*` and was never committed. `test_no_explanation_document_is_ignored_by_git` now guards against this.

### Datasets and models
`data/raw/*`, `data/processed/*`, `artifacts/models/*`, `*.joblib`, `*.cbm`, and per-run scores under `experiments/scores/`. `.gitkeep` files keep the empty folders.

### Batch upload scratch space
`backend/tmp/`, the default temporary folder for uploaded CSV files.

### Browser test output
`frontend/.e2e/` (generated test passwords, saved test sessions and screenshots), `frontend/test-results/` and `frontend/playwright-report/`.

### Tool output
Python caches, virtual environments, Node modules, build output, editor settings and logs.

## E. Classes Explained
None.

## F. Execution Flow
Git consults it when listing untracked files and when running `git add`.

## G. Input and Output
Not applicable.

## H. Important Technical Concepts
- **It only affects untracked files.** Anything already committed stays tracked until removed.
- **The frozen model is not in Git.** `model.joblib` is ignored, so a fresh clone needs it supplied separately (see `DEPLOYMENT.md`), and the API refuses to start without it.

## I. Example
```powershell
git check-ignore -v .env
```
