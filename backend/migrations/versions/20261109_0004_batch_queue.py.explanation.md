# 20261109_0004_batch_queue.py

Source: [backend/migrations/versions/20261109_0004_batch_queue.py](20261109_0004_batch_queue.py)

## A. File Purpose
Adds the batch queue: `worker_id`, `lease_expires_at` and `attempts` on `batch_jobs`, and the `batch_uploads` table for upload bytes.

## B. Why This File Exists
Phase 5 M4 made batch processing survive crashes and work across processes and containers.

## C. Dependencies
- **Libraries:** Alembic, SQLAlchemy.
- **Internal modules:** none.
- **External services / database:** PostgreSQL.
- **Depended on by:** `alembic upgrade head`, the migrate services, `test_migrations.py`.

## D. Every Function Explained

### `upgrade`
Adds the three columns (`attempts` defaults to 0) and creates `batch_uploads` with a cascading foreign key to `batch_jobs`.

### `downgrade`
Drops the table and columns.

## E. Classes Explained
None.

## F. Execution Flow
Runs after revision 0003.

## G. Input and Output
Output: three columns and one table.

## H. Important Technical Concepts
- **Cascade:** deleting a job deletes its stored bytes.
